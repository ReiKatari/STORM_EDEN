# STORM README Auditor

## Чек-лист проверки README.md:
- [ ] Главный заголовок центрирован: `<h1 align="center">НАЗВАНИЕ ПРОЕКТА</h1>`.
- [ ] В H1 отсутствуют иконки, эмодзи, логотипы и дефисы с уточнениями.
- [ ] Все заголовки H2 оформлены жирным шрифтом: `## **Название раздела**`.
- [ ] Запрещён символ `&` вместо союза «и», соблюдается Sentence case.
- [ ] Отсутствуют фразы вида «Доработан ReiKatari».
- [ ] Для форков чётко указан базовый эмулятор/утилита.
- [ ] Отсутствует блок «Безопасность и цифровые подписи».
- [ ] Отсутствует блок «Авторы и лицензия».
- [ ] Отсутствует дерево структуры директорий репозитория.
- [ ] Раздел «Благодарности» содержит полный список команд и библиотек строго без ссылок.
- [ ] В инструкциях указаны реальные имена файлов дистрибутивов.
