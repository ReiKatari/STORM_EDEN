# STORM Rejudge: Multi-Agent Consensus & Arbitration

## Назначение
Реализует принцип «Коллегия независимых экспертов + Судья-арбитр» для предотвращения ошибок, регрессий и слепых зон при разработке проектов экосистемы STORM SOFT.

## Структура коллегии рецензентов:
1. **Рецензент 1: Security & Hygiene Auditor**
   - Проверка безопасности, исключение утечек секретов, токенов, ключей и учетных данных.
   - Контроль размера файлов (исключение бинарников >100 МБ из коммитов).
2. **Рецензент 2: Performance & Architecture Auditor**
   - Анализ качества кода (C++20, C# .NET 9, TypeScript, Python).
   - Проверка многопоточности, задержек DPC, утечек памяти и предотвращение регрессий.
3. **Рецензент 3: Standards & Guidelines Compliance**
   - Проверка отсутствия префикса `v` в релизах.
   - Валидация структуры `README.md` (центрированный H1, благодарности без ссылок, отсутствие блоков безопасности и авторов).
   - Контроль авторства Git (`ReiKatari <45316432+ReiKatari@users.noreply.github.com>`).
4. **Главный Судья (Chief Judge / Orchestrator)**
   - Агрегирует независимые отчёты всех рецензентов.
   - Разрешает возникшие противоречия, отсекает ложные срабатывания и выносит единый итоговый вердикт.
