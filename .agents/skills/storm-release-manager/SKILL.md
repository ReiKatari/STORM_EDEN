# STORM Release Manager

## Обязательные правила при создании и редактировании релизов:
1. **Запрет префикса 'v'**: Использовать только чистые номера версий: `4.8.8`, `Релиз 4.8.8` (не `v4.8.8`).
2. **Запрет дублирования заголовка**: Никогда не помещать тег `# H1` с названием и версией в тело релиза.
3. **Запрет подписей**: Не добавлять «Собрано и опубликовано автором...» в конце.
4. **Сохранение ассетов**: Сохранять 100% прикрепленных файлов (APK, ZIP, EXE, 7z).
5. **Двойные переносы строк**: Обязательные пустые строки вокруг `<summary>` и `</details>`.
